Fundamentos de HTML: Párrafos

Los párrafos organizan el contenido textual de una página web de forma estructurada.

¿Qué es un párrafo?

La etiqueta <p> representa un párrafo de texto, es decir, una unidad independiente de contenido.

Usar párrafos ayuda a organizar el contenido y a aplicarle estilos con CSS.

Buenas prácticas

Usa <p> para párrafos reales y separa ideas distintas en párrafos diferentes.

Usa <br> solo para saltos de línea puntuales, no para crear espacios grandes.

Controla la apariencia (colores, tamaños, márgenes) con CSS.
